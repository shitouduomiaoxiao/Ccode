# C 语言练习代码库

按**编写日期**分类存放 C 语言练习工程。

## 目录约定

```
10/                 ← 月份（10 月）
└── 10.28/          ← 日期（10 月 28 日）
    └── Project1/   ← 当天的工程（一天多个工程用 Project1、Project2…）
```

- **一个日期一个目录**，目录里放当天写/改的工程
- 同一天有多个题目时：`Project1`、`Project2`……
- 同一个工程有多个版本时：用 `vN-YYYYMMDD/` 归档旧版本，`contact/` 这类不带版本号的目录放最新版（见 `10/10.17/`）
- 不提交构建产物：`.vs/`、`x64/`、`*.user`、`*.pdb`、`*.obj` 等已由 `.gitignore` 忽略
